# Verde interactive update

This update keeps the original Verde project folder and file names unchanged.

Added:
- Delete chats from the Recents list with a delete button.
- Delete the current chat from the More menu.
- Working header More menu: New chat, Rename chat, Share chat, Delete chat.
- Code blocks in AI responses now have Copy and Run controls.
- JavaScript code blocks can run in a restricted browser sandbox with a 2-second execution limit and no network connection.
- Copy remains available for code in any fenced code block.

No API key is included. Keep the local `src/backend/.env` file on the user's machine.
